# Definitions

The glossary of defined terms used across this platform. Each definition is written to be clear, stable, and consistent between the main site and the data site. Where a term has a formal technical meaning, the plain-language version is given first.

## Core terms

| Term | Definition |
|---|---|
| **Abstinence** | Sustained non-smoking over a defined period (e.g., continuous abstinence since a quit date). |
| **Craving** | An intense urge to smoke; has a pharmacological component (nicotine-adapted brain) and a conditioned component (triggers). |
| **Trigger** | A cue — internal (stress, alcohol, boredom) or external (coffee, driving, social events) — that activates the urge to smoke. |
| **Withdrawal** | The symptom syndrome that follows nicotine removal as the brain and body re-adapt; peaks in week 1, mostly resolves in 2–4 weeks. |
| **Lapse** | A single slip — one or a few cigarettes after a quit date. Not the end of the quit attempt. |
| **Relapse** | Return to regular, ongoing smoking; the quit attempt has ended. |
| **Quit attempt** | A deliberate, dated attempt to stop smoking, regardless of outcome. |
| **Quit date** | The planned day smoking stops. |
| **Nicotine dependence** | Neuroadaptation to nicotine producing craving, tolerance and withdrawal on removal. |
| **NRT** | Nicotine replacement therapy: patch, gum, lozenge, inhaler or spray delivering nicotine without tobacco smoke. |
| **Cold turkey** | Stopping smoking abruptly, without medication or gradual reduction. |
| **Gradual reduction** | Tapering cigarette consumption before a quit date, with or without nicotine products. |
| **Harm reduction** | Strategies to reduce harm without full abstinence (e.g., switching to lower-risk nicotine products); distinct from cessation. |
| **Dual use** | Using e-cigarettes or other products while still smoking cigarettes. |
| **Evidence strength** | Grading of a research record: Strong / Moderate / Limited, based on design and consistency. |

## Evidence vocabulary used on this platform

| Phrase | Meaning |
|---|---|
| **Evidence says…** | Statement supported by published research at evidence levels 1–5 (see [Research](../research/)). |
| **Community reports…** | Observation drawn from the de-identified experience database — not medical evidence. |
| **What remains uncertain…** | Genuine gaps or conflicts in the published evidence. |
